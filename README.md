# Portfólio: integrações bancárias

Dois projetos de demonstração, com banco e ERP simulados, cobrindo as duas frentes de uma integração
banco + ERP para administradoras de condomínios:

1. [`pagamentos-lote-dda`](pagamentos-lote-dda): pagar contas em lote, com DDA e dupla aprovação.
2. [`boletos-baixa-automatica`](boletos-baixa-automatica): emitir boleto/Pix e dar baixa automática por webhook.

São projetos próprios de demonstração, sem cliente real e sem integração com banco de verdade.
Ao apresentá-los, diga isso com clareza.
